Questions we get before the first call.

What does a typical engagement look like?

We start with a Solution Consultation call and a short discovery phase where we map one real process with the people who run it. From that we write a target architecture: agents, tools, data flows, security boundaries and a cost model. If it is worth building, we build it spoke by spoke, with evaluations and human checkpoints, and hand it over with monitoring, documentation and training. A first automated process typically goes live in weeks, not months.

How is pricing structured?

There is no price list and no packages. After discovery we propose a fixed-scope phase with a clear deliverable and price, so you decide phase by phase. We only recommend building when the automation is cheaper than the work it replaces.

Which models and platforms do you work with?

We design for the models companies already use: Claude, ChatGPT, Gemini, Kimi, DeepSeek, Mistral, Llama, Qwen and Grok. Architectures are model-agnostic where possible, with routing so each task uses the cheapest model that meets the quality bar. Cloud foundations run on AWS or Google Cloud, in your own account.

What is a hub-and-spoke agent architecture?

A central orchestrator (the hub) plans, routes and verifies work, while specialist agents, MCP tool servers, data sources and human reviewers (the spokes) each do one bounded job. Every edge is a typed tool contract with explicit permissions and logging. It keeps multi-agent systems explainable, testable and easy to extend: adding a capability means adding a spoke, not rewriting the system.

Do you build the system or only design it?

Both. We architect first, then build and operate, or hand a documented architecture to your internal team and support them. Either way the design is written down before the first line of code.

How do you keep AI agents safe with company data?

Agents never get raw access. They act through MCP servers and typed tools with scoped permissions, every call is logged, and steps with real risk (posting an invoice, sending a customer reply, creating a vendor) wait for human approval. Data stays in your cloud account; we design retrieval so agents answer from your documents instead of memorising them.
